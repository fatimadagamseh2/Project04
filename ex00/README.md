
# Personal Portfolio

## Description

This project is a responsive personal portfolio built using HTML5, CSS3, and JavaScript.

It presents my cybersecurity background, programming skills, projects, training, hobbies, and contact information.

## Features

- Responsive navigation bar
- About Me section with a profile photo
- Skills grid
- Cybersecurity and web development projects
- Training and courses
- Hobbies and interests
- Contact form
- Interactive light and dark theme switcher
- Responsive design for mobile and desktop

## Technologies

- HTML5
- CSS3
- JavaScript ES6+
- Git and GitHub

## Project Structure

- index.html
- style.css
- script.js
- assets/
- README.md

## How to Run

1. Open index.html in a web browser.
2. Make sure the profile photo is saved in the assets folder as profile.jpg.
3. Click the Theme button to switch between light and dark modes.
4. Use the navigation links to explore the website.

## Theme Switcher

JavaScript uses addEventListener to detect a button click. The classList.toggle method adds or removes the dark-mode class from the body element, and CSS changes the page colors.

## Contact Form

The form validates the required fields and displays a confirmation message. It does not send messages to a server.

## Responsive Design

Flexbox, CSS Grid, and CSS media queries help the website adapt to different screen sizes.
